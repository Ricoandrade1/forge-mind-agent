# Como contribuir

Ao enviar uma contribuição, confirmas que tens autorização para a disponibilizar e concordas que ela seja incorporada e distribuída pela Forge Labs sob a licença vigente deste repositório. Uma contribuição não concede direitos sobre a marca, o serviço ou o código privado do Forge Mind.

Obrigado por testares o Forge Mind Agent.

## Issues úteis

Uma boa issue inclui:

- O cliente usado, por exemplo Codex, OpenCode ou Claude.
- A versão do cliente.
- O sistema operativo.
- O comportamento esperado.
- O comportamento observado.
- Passos curtos para reproduzir o problema.

Usa apenas mapas e dados fictícios nos exemplos.

## Nunca publiques

- Chaves `fm_...`.
- Senhas ou tokens.
- Cookies ou códigos de sessão.
- Dados pessoais.
- Conteúdo privado dos mapas.
- Ficheiros de clientes.

## Alterações nas Skills

Mantém estas regras:

1. O agente lê o mapa antes de escrever.
2. O agente usa apenas IDs devolvidos pelas ferramentas.
3. O agente confirma o resultado depois de guardar.
4. O agente não inventa acesso nem conteúdo.
5. Ações destrutivas exigem intenção clara do utilizador.

## Pull requests

Explica o problema resolvido, os ficheiros alterados e como testaste. Mantém as alterações pequenas e evita incluir credenciais ou dados reais.
