# Segurança

## Credenciais

Nunca publiques uma chave `fm_...`, senha, token, cookie ou código de sessão numa issue, conversa, commit ou captura de ecrã.

As chaves pessoais devem ser inseridas apenas no campo seguro do cliente MCP. Podem ser revogadas dentro do Forge Mind.

## Comunicar uma vulnerabilidade

Não abras uma issue pública com dados sensíveis. Envia a descrição para `ricoandrade01@gmail.com`, incluindo o impacto, os passos de reprodução e apenas dados de teste.

## Escopo

O agente só deve conseguir consultar e alterar os mapas da conta autorizada. Qualquer acesso entre contas deve ser tratado como uma vulnerabilidade crítica.
